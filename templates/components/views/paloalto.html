PA Policy CLI Generator

팔로알토 방화벽 보안 정책(security rule) CLI 명령어를 행 단위로 생성합니다. 행 1개만 입력하면 단일 명령어, 여러 행을 입력하면 한 번에 여러 명령어가 생성됩니다. 작업유형(set/delete/move)에 따라 필요한 입력 항목만 아래에 표시됩니다. 여러 값이 필요한 항목(from/source/source-user/to/destination/service/application)은 콤마(,)로 구분하거나, 엑셀에서 여러 행을 복사해 그대로 붙여넣으면 자동으로 여러 값으로 인식됩니다.

엑셀로 채워서 업로드: 템플릿 다운로드

Service Object 생성

서비스 오브젝트 CLI 명령어를 생성합니다. 예: set service TCP-443 protocol tcp port 443
