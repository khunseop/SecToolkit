PA Policy CLI Generator

팔로알토 방화벽 보안 정책(security rule) 생성/수정/삭제/이동을 위한 PAN-OS CLI 명령어를 생성합니다.

대량 생성 - 그리드 입력

행을 추가해 여러 정책을 한 번에 정의하고 명령어를 일괄 생성합니다. 여러 값이 필요한 항목은 콤마(,)로 구분해 입력하세요.

작업유형 vsys rule_name disabled action from source source-user to destination service application description log-end log-setting move_position anchor_rule

대량 생성 - 엑셀 업로드

템플릿을 다운로드해 정책 정보를 채운 뒤 업로드하면 명령어를 일괄 생성합니다.
