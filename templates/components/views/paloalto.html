PA Policy CLI Generator

팔로알토 방화벽 보안 정책(security rule) CLI 명령어를 행 단위로 생성합니다. 행 1개만 입력하면 단일 명령어, 여러 행을 입력하면 한 번에 여러 명령어가 생성됩니다. 여러 값이 필요한 항목(from/source/source-user/to/destination/service/application)은 콤마(,)로 구분하거나, 엑셀에서 여러 행을 복사해 그대로 붙여넣으면 자동으로 여러 값으로 인식됩니다. delete는 필드를 비워두면 rule 전체를 삭제하고, 필드 하나에 값 하나만 입력하면 해당 객체 하나만 rule에서 삭제합니다(예: source에 1.1.1.1만 입력).

작업유형 vsys rule_name disabled action from source source-user to destination service application description log-end log-setting move_position anchor_rule
